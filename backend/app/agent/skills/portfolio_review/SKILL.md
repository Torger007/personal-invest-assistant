# 持仓复盘 Skill

版本：1.1.0。触发条件：用户在“问 AI”中点击“帮我分析当前持仓”等推荐提问，或在对话中提出等价的持仓分析、复盘、变化比较问题。

## 取数与判断

1. 基础复盘只读取当前用户带估值日期和来源的持仓。净值日期较早时点名该基金及日期，不将整个组合判为不可复盘。
2. 用户明确询问市场时才读取市场背景；询问规则操作时只读取指定基金已有的规则记录；明确比较至少两只基金时才比较指定基金。市场、规则和比较数据缺失只限制对应结论，不影响持仓事实。不得为了复盘自动为所有基金生成建议。
3. 数据不足时仅针对持仓估值缺口补查，不重复抓取已经有效的数据；整次运行最多 10 次工具调用，质量门触发的补查最多 2 次。
3. 候选关注项按持仓影响、变化幅度、风险紧迫性、用户已确认的偏好及证据质量排序，最多保留三项。没有足够证据时不要补满三项。
4. 将持仓变化、数据变化、规则变化和判断延续分开描述。没有上一次成功复盘时标记首次复盘，不引用普通聊天摘要作历史判断。同日数据未变时不能把措辞差异当成新变化。
5. 每项实质性结论引用当前证据 ID；历史变化还要引用上次复盘保存的证据 ID 和两次时间。不得编造证据 ID。

## 降级与动作边界

- 持仓估值缺失时降级；单基金净值较早只标注该持仓日期。市场或规则数据缺失时仅省略对应结论，不能把市场日期当作全部持仓估值日期。
- 上证、深证及创业板指数只作境内权益基金的背景，不能作为 QDII、债券或货币基金的行情证据。未接入对应市场基准时明确说明该板块背景不可核对。
- 规则按基金类别复用观察条件，不需要给每只基金手工设计规则；操作建议只在用户明确提出且指定基金、有对应有效规则记录时引用。
- 单基金操作、目标仓位和置信度只取有效规则决策产物；组合级具体调仓比例不得由模型计算。降级报告不得提出新增目标仓位。
- 复盘关注项只陈述证据事实与观察条件。引用规则信号时写“规则记录为……”，不要使用“建议买入/卖出/加仓/减仓”等由复盘本身发出的操作措辞。
- 输出必须符合 `PortfolioReviewResult`，包括状态、各数据时间、最多三项关注项、与上次相比、限制和证据 ID。模型提出的字段须通过服务端契约与证据校验后才能展示。
